# AI 文创手办 3D 生成与打印系统 项目方案

> **文档定位**：本文是目标方案与比赛路线图，不代表所列能力均已完成。
> 截至 2026-08-01，当前实施范围仅为 **单图生成无纹理 3D 网格并导出**；
> 文生 3D、纹理、DFM、自动修复、切片、Agent、微调和打印机联动均属于后续目标，
> 实际完成情况以《项目进度跟踪.md》和可复现产物为准。

## 当前 MVP 边界

1. 输入：透明背景 PNG，或主体清晰、背景干净的单张图片；
2. 处理：本地 Hunyuan3D-2mini 图生 3D；
3. 输出：无纹理 Trimesh 网格，可导出 STL、OBJ、GLB；
4. 验收：固定测试集、固定随机种子，记录耗时、峰值显存和导出文件；
5. 暂不承诺：文生 3D、彩色纹理和“生成即可打印”。

## 一、开源 3D 生成大模型选型

### 1.1 首选方案：腾讯 Hunyuan3D 2 系列

当前选择 Hunyuan3D 的主要原因是可本地部署、图生 3D 链路完整且便于二次开发。
项目使用前必须遵守 Tencent Hunyuan Community License；不能表述为“无版权风险”，
对外分发和商业化时还需检查许可证、NOTICE、地域和服务提供者披露要求。

1. **Hunyuan3D-2mini（学生项目当前主力）**
   - 参数规模：0.6B，官方资料给出的 Shape 生成显存需求约为 6GB
   - 核心能力：模型本体为图生 Shape；文生 3D 需要额外文生图模型，不属于当前 MVP
   - 输出能力：返回 Trimesh 网格，可导出 STL/OBJ/GLB；是否水密、可打印必须经 DFM 检查确认
   - 配套生态：官方提供 Gradio、API 和 Blender 示例；比赛展示和后续分发须遵守许可证
2. **Hunyuan3D-2.1 标准版**
   - 官方发布 3B Shape 模型、PBR 纹理管线及训练代码，适合作为后续云端高质量与微调路线
   - 生成时间随 GPU、分辨率、步数和纹理流程变化，不在方案中承诺固定秒数
   - 本地 8GB 笔记本不作为 2.1 完整管线的主要运行环境，部署前需单独压测

### 1.2 高精度备选：微软 TRELLIS 2.0

- 核心优势：官方定位为高保真图生 3D，可生成高分辨率几何与 PBR 材质
- 硬件门槛：官方要求至少 24GB NVIDIA 显存，且当前仅测试 Linux，不适合作为本机 8GB 离线兜底
- 打印风险：其开放曲面、非流形和内部结构表达能力面向数字资产，不等于天然可打印，仍须 DFM 与修复

### 1.3 轻量化备选（接入前需实测）

1. **TripoSR / Tripo Doodle**
   - 可作为快速草模候选，实际速度和显存以目标硬件实测为准
   - 草图输入路线需先做生成质量、许可证和可打印性评估
   - 适合快速创意打样，精细度通常弱于混元 3D 系列
2. **Step1X-3D**
   - 国内开源模型，支持文生 / 图生双模式
   - 是否适合作为兜底取决于本机实测、许可证检查和 DFM 通过率，暂不作为已接入能力

## 二、算力部署方案

### 2.1 云 GPU 服务器方案（主力开发推荐）

无需本地高性能电脑，按使用时长付费，学生项目性价比最优。

#### 推荐平台与配置档位

| 配置档位   | 推荐显卡     | 单小时参考价格 | 适用场景                     |
| ---------- | ------------ | -------------- | ---------------------------- |
| 入门调试款 | RTX 3060 12G | 0.6~1 元       | 轻量模型调试、代码开发       |
| 主力开发款 | RTX 3090 24G | 1.2~2 元       | 主流模型推理、高质量模型生成 |
| 高效量产款 | RTX 4090 24G | 2~3 元         | 批量生成、高清纹理渲染       |

#### 平台选择建议

- **首选平台**：AutoDL、恒源云。支持学生认证优惠，按秒计费，关机不扣费，自带主流深度学习环境镜像与 3D 模型一键部署包，开箱即用。
- **备选平台**：阿里云 / 腾讯云 GPU 服务器。稳定性强、带宽高，适合答辩前部署正式演示系统，可通过学生云计划获取低价包月额度。

#### 成本估算

云 GPU 价格变化较快，正式租用前按届时平台报价、模型上传下载时间、存储费和关机计费规则重新核算；本文不承诺固定月成本。

### 2.2 本地离线兜底方案

答辩现场存在断网风险，必须配置本地轻量化兜底：

- 本地笔记本部署 Hunyuan3D-2mini（6GB 显存即可运行），满足基础演示需求
- 目标：答辩前建立经过实测的预生成样例库；该模板库当前尚未完成

## 三、模型路线策略：开源为主，闭源补充

### 3.1 开源与闭源核心对比

| 对比维度   | 闭源方案（Meshy/Tripo AI 等）                  | 开源方案（Hunyuan3D/TRELLIS 等）                 |
| ---------- | ---------------------------------------------- | ------------------------------------------------ |
| 生成效果   | 通常易获得较稳定的展示效果，具体质量按服务实测 | 质量取决于模型、输入和后处理，必须用同一测试集对比 |
| 开发难度   | API 接入较快，但仍需任务、错误和成本管理       | 需部署环境、显存优化、调参和网格后处理             |
| 成本模式   | 按次或订阅收费，成本随调用量变化               | 需承担算力、存储、运维和模型下载成本               |
| 竞赛价值   | 仅调用 API 的自研证据较弱                      | 二次开发只有形成代码、指标和实物证据才构成创新     |
| 可控性     | 受服务接口限制                                | 可修改流程，但可控程度取决于模型是否开放训练能力   |
| 答辩稳定性 | 依赖网络、配额和服务状态                       | Shape 可离线；未缓存的模型和在线能力仍可能依赖网络 |

### 3.2 最优混合策略

沿用原项目「复杂能力闭源补充，核心执行开源自研」的分工逻辑，兼顾展示效果与竞赛技术价值：

1. 核心主干（竞赛主打）

   ：开源模型为核心

   - 3D 生成主干：云服务器部署 Hunyuan3D-2，本地部署 mini 版兜底
   - 目标：逐步自研 Agent 调度、打印合规检测、网格修复和轻量化；当前均未完成

2. 增值补充（效果增强）

   ：闭源 API 为辅

   - 可选接入 Meshy/Tripo AI API 作为高阶精修通道，做纹理优化与细节增强
   - 答辩可做「开源基础版 vs 闭源精修版」效果对比，体现技术视野

## 四、目标创新点设计（均为路线图，完成后方可作为比赛成果）

> 比赛材料只应展示已有代码、量化测试和实物打印能够证明的能力。以下目标按阶段实施，
> 未完成部分统一标注为“规划中”，避免将设想写成现有功能。

### 4.1 核心技术类创新（竞赛主打分）

#### 4.1.1 可打印性约束前置的生成式建模

**目标逻辑**：先建立“生成后 DFM 检测—修复—复检”的可验证闭环；在具备训练代码、数据集和对照实验后，再研究把打印约束前置到生成过程。最终目标是提高可打印率，而不是未经验证地承诺“生成即可打印”。

- **分阶段实现：**
  1. 先统一模型单位与目标尺寸，再按 FDM/光固化、材料、喷嘴/层高分别配置壁厚、悬垂和最小特征规则，禁止把 1.2mm 等值写成所有工艺通用常量；
  2. 第一阶段完成事后 DFM 检查、基础修复与复检，并统计修复前后通过率；
  3. 第二阶段基于 Hunyuan3D-2.1 训练代码评估 LoRA 或可微约束方案，通过消融实验验证是否真正提高可打印率；
  4. 只有达到预设指标后，才将“打印约束前置”作为已完成创新点。
- **竞赛价值**：用可复现指标证明 AI 生成与制造工艺结合，重点展示真实打印成功率和耗材变化。

#### 4.1.2 草图保真分层生成 Agent

**目标逻辑**：解决手绘草图转 3D 的轮廓跑形和细节丢失问题；当前尚无 Agent 或分层生成实现。

* **规划实现（需新建视觉识别与 Agent 调度能力）：**

1. **结构层生成**：提取草图关键轮廓并研究可控条件输入，以轮廓相似度衡量结构保真，不承诺 1:1 还原；
2. **细节层生成**：Agent 自动拆解细节需求（服饰纹理、面部表情、底座花纹），分批次补全高精度细节，避免整体生成时结构崩坏；
3. 中间支持人工干预调整，比如 “保留头部造型，修改衣服纹样”，实现可控式生成。

* **竞赛价值**：比普通 “图生 3D” 多了一层结构保真逻辑，Agent 分治的思路技术含量更高，答辩时现场手绘演示效果极具冲击力。

#### 4.1.3 特征感知的智能支撑与摆放优化

**创新逻辑**：普通切片软件的支撑是纯几何计算，你们结合 AI 对模型的功能 / 外观理解，实现「外观面零支撑、非关键面最少支撑」，兼顾打印成功率和表面质量。

- **规划实现（需新建特征识别与优化模块）：**
  1. Agent 自动识别手办的**外观面**（正面面部、服饰正面）、**非外观面**（背部、底部）、**功能结构**（卡扣、底座）；
  2. 自动计算最优打印摆放角度，让外观面尽量避开支撑接触，同时计算最少支撑量，减少耗材浪费和后期打磨工作量；
  3. 自动生成易拆除的薄壁支撑，输出适配你们 3D 打印机的专属切片参数。
- **竞赛价值**：深度绑定 3D 打印实体场景，不是纯软件生成，而是真真切切解决打印后处理的痛点，落地性极强。

### 4.2 场景差异化创新（垂直赛道壁垒）

#### 4.2.1 国潮 / 校园 IP 定向微调的专属生成模型

**创新逻辑**：针对文创赛道做垂直领域微调，生成效果比通用模型更贴合需求，同时可以绑定校园、地方文化做落地场景。

- **落地方式：**
  1. 基于 Hunyuan3D 等开源基础模型，用国潮手办、非遗纹样（祥云、缠枝纹、京剧脸谱、神兽纹样）做小规模 LoRA 微调，打造专属国潮手办生成模型；
  2. 可拓展校园文创方向：输入校徽、校园地标，自动生成 Q 版校园手办、毕业纪念摆件，直接对接校园周边落地场景。
- **竞赛价值**：有明确的落地场景和商业想象空间，适配 “互联网 +”“挑战杯” 的文化创意、乡村振兴 / 非遗传承赛道，容易拿到高分。

#### 4.2.2 模块化可拼接手办自动生成与公差适配

**目标逻辑**：跳出“一体成型手办”的局限，规划可拼装、可换配件的潮玩手办生成；参数化设计与 BOM 模块尚需建设。

- **规划实现（需新建参数化标准件与 BOM 架构）：**
  1. Agent 自动将手办拆分为头部、身体、底座、配件（武器、饰品）等独立模块，自动生成通用卡扣接口；
  2. 内置 3D 打印公差补偿（比如卡扣预留 0.1-0.2mm 间隙），保证打印出来的零件能精准拼接；
  3. 自动生成零件 BOM 清单、拼装说明，支持用户自由搭配配件，实现 “一个底座换多个头部” 的潮玩玩法。
- **竞赛价值**：玩法性强，符合当下潮玩市场的趋势，把原来机械领域的参数化、BOM 能力跨界复用，创新点巧妙且工作量可控。

#### 4.2.3 实物特征迁移的混合驱动生成

**创新逻辑**：支持 “实物照片 + 文字描述” 混合输入，提取现有实物的特征融合生成新模型，比单纯文生 / 图生适用场景更广。

- **落地方式：**
  1. 用户拍一个现有小物件（比如印章、手办残件、校徽、非遗摆件），AI 提取其造型、纹样特征；
  2. 配合文字指令（“改成 Q 版手办”“加个古风底座”“放大成 10cm 摆件”），融合生成全新的 3D 打印模型；
  3. 典型场景：老物件文创化改造、残件复刻、IP 衍生设计。
- **竞赛价值**：多模态融合的创新点更饱满，落地场景丰富，适合展示实体改造的前后对比。

### 4.3 工程体验类创新（答辩展示加分）

#### 4.3.1 云端 - 本地协同生成架构

云端部署高精度模型做最终生成，本地部署轻量化模型做草稿预览与结构确认，内置离线模板兜底方案，兼顾生成质量、速度与答辩稳定性，工程完整度优于单模型项目。

#### 4.3.2 打印全流程数字孪生与耗材成本核算

**创新逻辑**：打通从生成到打印的全链路数据，不只是输出 STL 文件，而是给用户完整的打印解决方案。

- **落地方式：**
  1. 模型生成后，自动模拟打印过程，精准计算打印时长、耗材用量、预估成本；
  2. 在明确打印机型号、通信协议和安全确认流程后，再开发一键发送任务与进度同步；
  3. 生成打印工艺单（层高、曝光时间、支撑参数），配套 Three.js 做打印过程动画预览。
- **竞赛价值**：全流程闭环，有实体打印机联动，答辩时现场生成、现场算成本、现场启动打印，视觉冲击力远强于纯软件演示。

#### 4.3.3 打印残次品 AI 补全修复工具

**创新逻辑**：解决 3D 打印的高频痛点 —— 打印失败 / 缺损后无需整体重打，AI 补全缺损部位，节省耗材和时间。

- **落地方式：**
  1. 用户给打印坏的手办拍多角度照片，多模态模型识别缺损部位的形状、尺寸；
  2. AI 自动生成缺损部位的补全 3D 模型，自动预留粘接余量，打印后直接粘合修复；
  3. 适合断手、缺角、底座损坏等常见打印失败场景。
- **竞赛价值**：非常务实的痛点解决，体现项目不是 “为了 AI 而 AI”，而是真的解决 3D 打印的实际问题，实用性拉满。

### 4.4 价值生态类创新（拔高项目高度）

#### 4.4.1 面向小众圈层的轻量化定制工具

针对手办圈、BJD 娃圈、兵人圈、桌游爱好者等小众圈层，做专属比例的配件生成：比如 12 分 BJD 娃娃的家具配件、兵人的武器装备、桌游棋子定制，自动匹配标准比例，精准适配圈层需求。这类用户付费意愿强，商业落地路径清晰，适合创业类赛道。

#### 4.4.2 开源工具链共建

在相关模块真实完成并通过许可证检查后，再选择性开源自研的 3D 打印适配、DFM 检查和评测工具，并提供可复现实验与使用文档；当前没有可发布的 LoRA 或 DFM 成果。

### 4.5 耗材与成本优化

目标是在满足最小壁厚、排液孔和结构强度要求的前提下进行中空设计，并通过切片结果计算耗材、时间和成本变化。中空设计本身不能直接等同于安全或节省成本。

## 五、建议优先验证的两项创新

1. **模块化编辑与拆件**：允许用户指定头部、身体、底座或配件模块进行局部替换，并生成带工艺公差的连接结构；
2. **生成后评估返工闭环**：对生成网格执行尺寸标准化、DFM 评分、缺陷定位、修复和再次评分，以量化结果决定是否返工。
