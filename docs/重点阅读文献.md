# 适配「AI 文创手办 3D 生成 + 3D 打印 + LLM Agent」项目必读论文分类清单

按**项目四大核心模块**划分，全部为顶会/顶刊高引用论文，标注每篇对项目的**直接借鉴价值**。优先精读带【必看】标签的论文。

## 一、通用高质量文生/图生 3D 底座（模型选型与系统架构参考）

### 1. CLAY: Controllable Large-scale Generative Model for Creating High-quality 3D Assets【必看】
- **来源**：SIGGRAPH 2024（荣誉提名）
- **核心价值**：国内影眸科技开源，工业级通用 3D 生成，适配手办、潮玩、雕塑；原生支持网格拓扑规整、PBR 纹理。
- **可借鉴**：分层粗细生成逻辑、多视图一致性约束、轻量化网格输出流程，解决手办背面穿模、细节崩坏问题；完整工程链路可复刻为系统主流程。

### 2. DreamFusion（2022）【必看】
- **来源**：Google Research / ICLR 2023
- **核心价值**：**文生 3D 领域奠基之作**，首次提出文本驱动 + 扩散模型引导 + NeRF 优化的三维生成范式。
- **项目结合点**：传统 AI 三维生成仅优化视觉相似度，完全忽略模型可制造性；本研究在其基础上新增打印约束优化，直接支撑"生成即打印"创新点。

### 3. Magic3D（NVIDIA, 2022）
- **来源**：NVIDIA / ICLR 2023
- **核心价值**：对 DreamFusion 的改进——生成速度更快、分辨率更高、网格提取效果更优。
- **项目对应**：Magic3D 生成美观模型 → 你的系统生成**可直接打印**的模型，阐明网格后处理优化的必要性。

### 4. 3DTopia-XL: Scaling High-Quality 3D Asset Generation via Primitive Diffusion
- **来源**：arXiv 2024
- **核心价值**：图元基扩散 3D 生成，将模型拆分为基础几何图元，完美匹配**模块化可拼接手办**创新点。
- **借鉴**：图元拆解思路，实现手办头/身体/配件自动拆分、卡扣接口生成。

### 5. HexaDream: Hexaview Prior and Constraint for Text-to-3D Creation
- **来源**：FCS 2025（国内）
- **核心价值**：六视图先验约束生成，专门适配手绘草图/单张人设图生成手办，中文数据集友好。

### 6. PHIDIAS: Multi-condition 3D Generation with Reference-Augmented Diffusion
- **来源**：ICLR 2025
- **核心价值**：支持**文字 + 图片 + 3D 参考**混合输入，对应「实物特征迁移混合生成」创新。

## 二、开源 3D 生成框架技术报告（工程落地直接相关）

### 1. 混元 3D-2 / 混元 3D-2.1【必看 ★★★★★】
- **技术报告**：Hunyuan3D 2.0: Scaling Diffusion Models for High-Resolution 3D Asset Generation
- **必读理由**：项目以混元 3D 为核心生成引擎。重点研读整体架构：图像/文本输入 → 形状生成模型 → 纹理生成模型 → 网格+纹理成品。
- **创新改进**：在原有流程后新增：可打印约束智能体 → DFM 评估 → 自动修复循环，这是论文的核心创新贡献。

### 2. TRELLIS（微软）【必看 ★★★★★】
- **论文标题**：Structured 3D Latents for Scalable and Versatile 3D Generation
- **核心创新**：不直接生成原始网格，而是采用结构化表征。流程：图像输入 → 三维结构化隐空间 → 网格/高斯场/纹理输出。
- **项目价值**：模块化可拼接手办方案依赖结构化三维表征（拆分头部、身体、服饰、底座），TRELLIS 思路比传统网格生成器更贴合。

### 3. InstantMesh
- **论文标题**：InstantMesh: Efficient 3D Mesh Generation from a Single Image
- **核心优势**：推理速度极快（~10s）、网格拓扑优质、正反面纹理一致。
- **落地场景**：两段式流水线——InstantMesh 快速原型预览 → 混元 3D 高清精细生成（工程创新亮点）。

## 三、3D 打印可制造性约束（项目最大差异化核心，全部【必看】）

> 这一组是区别于 Meshy 等纯视觉生成工具的核心理论支撑，解决「生成即可打印」问题。

### 1. From Prompts to Printable Models: Support-Effective 3D Generation via ODPO【必看】
- **来源**：arXiv 2025
- **核心价值**：业界首篇**生成阶段嵌入支撑优化约束**的论文，通过偏好优化让 AI 原生生成少悬空、易打印造型。
- **直接复用**：智能支撑与摆放优化创新点的理论依据；损失函数设计可嵌入 LoRA 微调，实现前置打印约束生成。

### 2. Decoder Generates Manufacturable Structures: 3D-Printable Object Synthesis【必看】
- **来源**：arXiv 2026
- **核心价值**：完整给出 4 项 3D 打印硬约束数学定义：
  1. 悬垂角 ≤ 45°
  2. 最小壁厚 ≥ 1.2–2mm
  3. 封闭空腔自动填充
  4. 支撑最小化
- **落地**：DFM 可打印检查规则库、生成阶段约束编码直接照搬论文公式。

### 3. Printable Neural Fields: A Framework for 3D Printing Neural Fields【必看】
- **来源**：SIGGRAPH Asia 2023
- **核心价值**：顶会首套隐式 3D 生成与 3D 打印微分约束一体化框架，将 FDM/光固化打印规则嵌入 NeRF/SDF 生成损失。
- **可复用**：微分可打印损失函数（最小壁厚、悬垂角、封闭空腔、自相交抑制）；SDF 隐式场自动加厚薄壁、输出水密网格。

### 4. Fixing Generative 3D Models with Differentiable Slicing【必看】
- **来源**：CVPR 2024
- **核心价值**：提出可微分切片，在 3D 生成循环内实时仿真打印缺陷并反向修正几何。
- **可复用**：打通「生成→仿真切片→缺陷修复」闭环，论证系统区别于 Meshy 的核心壁垒——内置打印仿真校验。

### 5. PhysiOpt: Physics-Driven Shape Optimization for 3D Generative Models【必看】
- **来源**：SIGGRAPH Asia 2025（MIT）
- **核心价值**：潜空间可微分物理优化，生成后无损修复薄壁、断裂结构。
- **适配**：打印残次品 AI 补全、薄壁自动加厚功能的算法基础。

### 6. BRICKGPT: Generating Physically Stable and Buildable Brick Structures【必看】
- **来源**：ICCV 2025（最佳论文）
- **核心价值**：顶会最佳论文标杆，核心思想——**生成时兼顾视觉效果 + 物理可制造**，完整论证"生成+制造约束融合"的学术创新性。
- **用途**：写论文、答辩引言可直接引用拔高立意。

## 四、LLM Agent 分层 3D 建模（多智能体架构参考，【必看】）

> 全部采用多智能体分层拆解 + 自动纠错，完美适配「草图保真分层生成 Agent」架构。

### 1. LL3M: Large Language 3D Modelers【必看】
- **来源**：arXiv 2025
- **核心价值**：多 LLM 智能体协作写 Blender 建模脚本，分工规划、建模、报错修复。与项目逻辑 1:1 匹配：
  - 需求解析 Agent → 3D 生成 Agent → DFM 校验 Agent → 修复 Agent
- **借鉴**：Agent 自纠错循环流程、RAG 知识库存储打印规则/建模 API 文档。

### 2. ShapeCraft: LLM Agents for Structured 3D Modeling【必看】
- **来源**：arXiv 2025
- **核心价值**：直接集成 Hunyuan3D 作为底层生成引擎，技术栈完全一致；分层树形拆解造型（头部/服饰/底座），实现粗结构→细节分层生成。

### 3. Natural Language to 3D Geometric CAD: Multi-Agent LLM Framework
- **来源**：NVIDIA GTC 2026
- **核心价值**：原机械 CAD 项目理论源头，分层参数化分解、迭代校验修复；可将机械领域分层思路迁移到手办文创建模。

### 4. L3GO: Chain-of-3D-Thoughts for Generating Objects
- **来源**：arXiv 2025
- **核心价值**：3D 思维链 CoT 提示词工程，让大模型推理空间结构、打印缺陷，用于 DFM 模块自然语言优化建议生成。

### 5. CADDesigner: 概念化 CAD 模型生成智能体
- **适配度**：★★★★★（最高优先级）
- **核心匹配点**：完全复用 LLM Agent + 文本/草图双输入 + 自动生成建模脚本 + 迭代纠错架构，与文创手办分层生成 Agent 逻辑 1:1 对应。
- **可借鉴**：ECIP 显式上下文命令范式（提升建模成功率）；多模态输入融合（文字+手绘草图）；循环纠错链路（生成→校验→LLM 自动修复）。
- **短板**：原生面向机械参数 CAD，需将 SolidWorks/CadQuery 建模链路替换为 Hunyuan3D 网格生成。

## 五、草图/手绘转 3D 手办专项（答辩现场演示核心）

### 1. SketchDream: Sketch-based Text-to-3D Generation and Editing【必看】
- **来源**：arXiv 2024 / SIGGRAPH 2024
- **核心价值**：手绘草图 + 文字联合生成 3D 网格，3D ControlNet + 多视图深度约束解决草图轮廓变形；支持局部草图修改手办细节。
- **复用**：草图预处理、轮廓对齐、分层粗细生成完整 Pipeline。
- **注意**：原生输出 NeRF 格式，需额外网格提取；单次生成耗时 ~1 小时（A100），适合高端定制场景而非量产。

### 2. Sketch2NeRF: Multi-view Sketch-guided Text-to-3D Generation
- **来源**：arXiv 2024
- **核心价值**：多视角草图约束方案，适合人设三视图生成完整手办，解决单张草图侧面、背面结构崩坏。

### 3. SketchFaceGS: Sketch-Driven 3D Face Generation
- **来源**：CVPR 2026
- **核心价值**：针对人物面部、五官草图高精度还原，专门适配 Q 版手办、古风人物面部生成。

### 4. DreamControl: Control Structural Layout of Text-to-3D Generation with 3D Skeletons【必看】
- **来源**：CVPR 2024
- **核心价值**：用 3D 骨骼/轮廓草图做硬约束，强制 AI 遵循手绘人体/潮玩结构；支持粗结构→细节分层生成；按骨骼自动拆分头部、身体、配件。

## 六、3D 编辑/可控生成（局部修改与精细化）

### 1. Instruct-NeRF2NeRF
- **来源**：ICCV 2023
- **核心价值**：基于自然语言指令的三维场景编辑。
- **适配场景**：用户指令"仅修改服饰"——仅局部模块重绘，其余结构保留，为**局部三维编辑**提供理论支撑。

### 2. HoLa-BRep: 多模态输入秒出参数化 CAD 模型
- **适配度**：★★★★★
- **核心价值**：业内顶尖多模态结构化 3D 生成方案，支持文本/草图/图像输入，生成拓扑合法、水密边界表示模型。
- **可借鉴**：统一全局隐空间编码几何+拓扑，从根源减少破面、自相交；多模态特征对齐方案；结构化生成先验用于可打印性约束前置生成。

## 七、网格修复与后处理

### 1. Difix3D+: 单步扩散模型修复 3D 重建伪影
- **来源**：CVPR 2025
- **核心价值**：单步扩散快速修复 3D 视觉伪影、缺失细节。
- **适配**：草图转 3D 后五官/服饰细节修复；打印残次品 AI 补全修复（断手、缺角、空洞补全）。
- **注意**：原生针对 NeRF/3DGS 渲染图修复，需改造适配网格几何缺陷修复，重点看单步扩散修复流水线章节。

### 2. Manifold Plus: Robust and Efficient Mesh Repair
- **来源**：SIGGRAPH 2023
- **核心价值**：工业级流形网格修复算法，一键处理非水密、破洞、自相交、重叠面片、法向反转。
- **落地**：轻量化网格修复管线可嵌入 Python 后处理；缺损区域拓扑补全逻辑；输出纯流形水密网格，直接导入切片软件。

## 八、闭环架构与工程参考

### 1. Reac-Discovery: 融合数学建模/机器学习/自动化实验的闭环生成架构
- **来源**：Nature 子刊
- **核心价值**：几何生成→增材制造→检测评估→ML 优化迭代 完整自驱动闭环。
- **可借鉴**：三层闭环架构（生成模块→制造打印→检测优化），直接套用做系统流程图；几何拓扑参数+打印工艺参数联合优化思路。
- **注意**：赛道是化工催化结构 3D 打印，仅复用闭环架构与多参数联合优化思想。

### 2. ImmerseGen: Agent-Guided Lightweight 3D Proxies
- **来源**：arXiv 2025
- **核心价值**：轻量化网格简化、特征保留算法，用于模型轻量化导出、Three.js 网页预览。

### 3. MS2Mesh-XR: Multi-modal Sketch-to-Mesh Generation
- **来源**：XR 2025
- **核心价值**：多模态（草图+文字）输入交互逻辑，参考做前端 Web 交互页面设计。

## 九、智能体/多智能体框架（工程实现参考）

### 1. AutoGen（微软）
- **来源**：Microsoft Research
- **核心价值**：多 Agent 框架，支持不同角色智能体分工协作。
- **应用**：设计「需求解析 Agent」「3D 生成 Agent」「DFM 检查 Agent」「后处理 Agent」四个角色自动协作。多智能体协同架构比单 Agent 技术亮点更突出。

### 2. LangGraph
- **核心价值**：多步骤、带循环纠错的复杂工作流。
- **应用**：实现「结构层生成→细节层生成→DFM 校验→不合格回流修复」循环工作流，完美匹配生成后二次评测、迭代返工优化。

## 十三、核心研究思路总结

> **不要单纯对标 Meshy 等工具比拼三维视觉生成效果。**

项目最强的学术/竞赛差异化切入点：

**从"AI 生成三维资产"，升级为"AI 自主设计可落地量产的文创产品"。**

这一核心定位，是你的项目真正具备独特竞争力的关键。
