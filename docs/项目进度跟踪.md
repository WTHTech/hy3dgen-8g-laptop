## 四、核心交付：分阶段推理封装 (`scripts/inference.py`)

### 4.1 设计原则

1. **当前 MVP 只生成 Shape，不启用未下载的文生图和纹理模型**
2. **透明 PNG 保留 alpha；普通 RGB 图片可选择调用 rembg**
3. **每个阶段使用 `try/finally`，成功或异常都会解除引用、迁回 CPU 并清理 CUDA 缓存**
4. **使用 `from_single_file()` 直接从本地文件加载，不依赖 HuggingFace Hub 网络**
5. **启用 `enable_model_cpu_offload()` 降低峰值显存（8GB VRAM 适配关键）**
6. **通过固定 `seed` 支持同配置复现实验**

### 4.2 API 接口一览

```python
from scripts.inference import Hunyuan3DGenerator

gen = Hunyuan3DGenerator(
    model_dir='D:/AI文创3D打印/models',  # 模型根目录
    variant='turbo',                       # 'turbo' | 'standard'
)

# ── 当前核心推理 ──
mesh = gen.generate_shape(
    image,
    seed=0,
    remove_background=False,                # 透明 PNG 不需要抠图
)                                             # 图→3D 形状（加载→推理→卸载）

# ── 格式导出 ──
gen.export_stl(mesh, 'output.stl')          # STL（无纹理，打印前仍需 DFM/切片验证）
gen.export_obj(mesh, 'output.obj')          # OBJ
gen.export_glb(mesh, 'output.glb')          # GLB（当前无纹理）

# ── 一站式接口 ──
gen.image_to_3d(image, export_stl=...,      # 图生3D全流程
                export_glb=..., with_texture=False)

# ── 状态查询 ──
gen.memory_status()                         # 查看显存+模型加载状态
```

### 4.3 generate_shape 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `image` | 必填 | 输入图片路径或 PIL.Image |
| `num_inference_steps` | 按 variant | turbo 25，standard 50；可显式覆盖 |
| `guidance_scale` | 5.0 | CFG 引导强度 |
| `octree_resolution` | 256 | 网格提取分辨率（越高越精细，越耗显存） |
| `num_chunks` | 5000 | MC 分块数（降低可减少峰值显存） |
| `seed` | 0 | 随机种子，用于复现实验 |
| `remove_background` | `False` | RGB 图片是否调用 rembg；透明 PNG 不需要开启 |

### 4.4 显存管理机制

```
generate_shape():
  1. _load_shape_pipeline()      → 加载 Shape 模型 + CPU Offload
  2. pipeline(image)             → 推理生成网格
  3. finally                     → 无论成功/异常都执行卸载
  4. _unload_shape_pipeline()    → 移除 hook + 迁回 CPU + gc + empty_cache
  5. return mesh                 → 返回 trimesh 对象

generate_texture():  （保留的后续纹理分支，模型未下载、当前未验收）
  1. _load_tex_pipeline()        → 检测 Shape 是否已卸载，未卸载则报错
  2. pipeline(mesh, image)       → 生成纹理
  3. _unload_tex_pipeline()      → 释放显存
  4. return textured_mesh

memory_status() 可随时检查：
  - VRAM 使用量
  - Shape pipeline 是否加载
  - Texture pipeline 是否加载
  - 是否出现双模型共存（!! 警告 !!）
```

### 6.2 DFM 检查项（6 大类 21 项）

#### 前置处理（P0 阻断级）

- [x] **P0 单位标准化**：复制原网格，归一化模型缩放至目标毫米高度并放置到 Z=0；报告返回 `prepared_mesh`，全量精检与后续导出必须使用同一对象
- [x] **P1 底面平台校验**：底面投影凸包面积低于阈值时阻断
- [x] **P2 外框超限**：AABB 包围盒超过打印机成型尺寸时阻断

#### 几何拓扑（G0 阻断级 — 切片崩溃致命缺陷）

- [x] **G1 水密性**：`trimesh.is_watertight`
- [x] **G2 自相交**：pymeshlab 自相交面选择；超过同步面数上限时返回 `UNKNOWN`，待服务器异步检测
- [x] **G3 非流形边**：统计 `edges_unique_inverse` 中被 ≥3 个面共用的边
- [x] **G4 翻转法向**：`is_winding_consistent` + 水密网格有符号体积
- [x] **G5 重复/零面积面片**：面顶点索引排序去重 + 尺度相关退化面积容差
- [x] **G6 孤立游离碎面**：`trimesh.split()` 连通分量面积 < 主体 1%

#### 壁厚与结构（W 级 — 警告/阻断按工艺可配置）

- [x] **W1 最小壁厚（基础估算）**：确定性表面采样 + 向内射线，按 `index_ray` 配对并取最近命中；仍需复杂薄壳真值集验证
- [ ] **W2 最小特征尺寸**：骨架分析 + SDF 检测细剑尖/飘带末梢等脆弱结构
- [ ] **W3 拉丝/细长比**：截面分析柱体高度/最小宽度 > 10~15
- [ ] **W4 镂空点阵壁厚**：SDF 体素化度两实体面间距，精准定位薄弱点

#### 空腔检测（C 级）

- [ ] **C1 封闭空腔**：SDF 体素化 → 3D 连通域 → 排除触及边界的半开放凹槽 → 输出空腔坐标/体积
- [ ] **C2 排液孔**（光固化）：中空模型无排液孔 → "吸力杯"效应，打印失败

#### 悬垂与支撑（S 级）

- [x] **S1 悬垂角**：只统计 `normal_z < -cos(临界角)` 的朝下面，排除平台底面并按面积占比判定；竖直侧壁不再误报
- [ ] **S2 桥接检测**：水平悬空两点间跨度 > 15mm → 拉丝风险（FDM 独有）
- [ ] **S3 悬空孤岛**：分层切片 + 连通比对，某层新出现轮廓下方无对应 → 坍塌
- [ ] **S4 最小支撑接触面积**：悬垂面投影面积累加 < 3mm² → 支撑脱落
- [ ] **S5 支撑去除干涉**：pymeshlab 布尔交集 支撑 ∩ 模型 → 嵌入风险

#### 尺寸与装配（D 级）

- [ ] **D1 内孔最小孔径**：trimesh 截面 + Shapely `interiors` 提取内轮廓 < 喷嘴直径
- [x] **D2 装配间隙（基础版）**：`trimesh.ProximityQuery` 多零件最近距离；单部件为 `NOT_APPLICABLE`
- [ ] **D3 螺纹特征**：高频切片 + scipy 周期分析，牙距/牙高 < 成型极限

### 6.3 分层质检流水线

```
第一级：快速粗筛（同步；G2 耗时随面数增长）
  P0 标准化 → P1 平台 → P2 外框 → G1~G6 拓扑 → S1 悬垂角
  FAIL 或阻断项 UNKNOWN → 不进精检；高面数模型转服务器异步任务

第二级：精细精检
  当前可靠基础项：W1 壁厚抽样、D2 装配间隙
  W2~W4、C1~C2、S2~S5、D1、D3 在真值测试验收前返回 UNKNOWN/N/A，不计分

第三级：修复 + 仿真
  MeshFix/pymeshlab 修复 → 复检闭环 → CuraEngine 切片 → GCode 报错解析
```

### 6.4 分级修复策略

| 级别 | 操作 | 工具 |
|:--:|------|------|
| 轻量 | 合并重叠面、统一法向、删除零面积三角、填充微小破洞 | pymeshlab |
| 中度 | 缝合缝隙、拆分自相交面片 | pymeshlab / MeshFix |
| 重度 | V-HACD 重网格化、网格简化 | trimesh / MeshFix |
| 兜底 | 无法修复 → 退回生成阶段换 seed 重新生成 | 自研调度 |

> 修复完成后必须重新跑全部检测（检查→修复→复检闭环），确认缺陷消除且无新增问题。

### 6.5 可打印性评分

| 维度 | 权重 | 评分逻辑 |
|------|:--:|------|
| 水密/拓扑 | 25% | 水密+无非流形=满分，每项缺陷扣分 |
| 壁厚 | 25% | 最小壁厚/目标壁厚 × 100，< 阈值直接 0 |
| 悬垂/支撑 | 20% | 悬垂面占比越少分越高，> 30% 面积 ≤ 60 |
| 尺寸合规 | 15% | 外框/内孔/间隙均合规 = 满分 |
| 特征/结构 | 10% | 最小特征尺寸/喷嘴直径 × 100 |
| 空腔 | 5% | 无封闭空腔或有排液孔 = 满分 |

**输出**：总分 + 各维度红黄绿灯仪表盘 + JSON 结构化报告 + 缺陷可视化热力图

## 八、已知问题 & 注意事项

1. **当前只做图生 3D**：文生图模型未下载，`text_to_3d` 入口已暂时移除
2. **纹理模型未下载**：当前支持无纹理 STL/OBJ/GLB 导出，GLB 彩色导出尚未验收
3. **当前产物仅为冒烟质量**：完整步数、较高分辨率和 10+ 测试图尚未验证
4. **RGB 背景**：默认不自动抠图，优先使用透明 PNG；需要时传入 `remove_background=True`
5. **RTX 5060 架构兼容性**：需 PyTorch with CUDA 12.8+（已处理，不支持 cu124 旧版 PyTorch）
6. **首次推理可能较慢**：CUDA kernel 编译有预热开销
7. **CPU Offload 依赖 `accelerate` 包**：已安装，不可卸载
8. **依赖警告**：当前 `requests` 会提示缺少字符检测依赖，不影响本地 Shape 冒烟测试，后续整理依赖清单时处理
9. **上游代码通过 Git Submodule 引用**：所有项目改动在 `scripts/inference.py` 和 `dfm/` 中，不修改 Hunyuan3D-2 上游源码
10. **DFM 精检仍是阶段性交付**：W2~W4、C1~C2、S2~S5、D1、D3 当前明确返回 `UNKNOWN`/`NOT_APPLICABLE`，不能作为比赛演示中的“已完成检查”；优先逐项建立几何真值集后再启用
