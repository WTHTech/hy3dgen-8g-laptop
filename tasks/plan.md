# AI 底座图像预处理实施计划

## 依赖顺序

1. 固定公共请求、结果与触发策略。
2. 实现纯本地图像分析和蒙版，作为外部调用前置条件。
3. 实现 OpenAI 提供方边界，所有网络行为可替换为假客户端。
4. 实现流水线的保存、校验、manifest 和安全回退。
5. 增加 CLI，并以可选参数接入 Hunyuan3D 原始图生 3D入口。
6. 完成单元、全量和单张真实 API 验证。
7. 以独立提供方接入 Seedream 5.0 Pro，不复用 OpenAI 官方端点逻辑。

## 关键风险与缓解

- AI 修改人物主体：限制底部 mask，并校验输出 alpha 主体面积。
- 底座与人物仍未连接：提示词要求 3%–5% 嵌入，最终由 DFM P1/G6 验证。
- API 不稳定或限流：超时、有限重试和原图回退；不自动循环付费调用。
- 密钥泄露：只读环境变量；异常与 manifest 不含请求头和密钥。
- 供应商耦合：公共 `ImageEditProvider` 协议隔离 SDK。
- 测试消耗额度：默认全部使用假客户端；真实验证单独显式运行。
- Seedream 无 mask：发送底部留白画布并使用严格编辑提示词；输出不透明或主体缺失即回退。

## 验证检查点

- 检查点 A：纯图像分析和蒙版聚焦测试通过。
- 检查点 B：提供方参数、解码和安全错误测试通过。
- 检查点 C：流水线成功/失败/禁用三条路径通过。
- 检查点 D：Hunyuan3D 入口轻量测试和全量测试通过。
- 检查点 E：A01 真实编辑输出及 manifest 生成，人工视觉复核。
